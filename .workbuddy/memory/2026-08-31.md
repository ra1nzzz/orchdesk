## 事故：WorkBuddy safe-delete shim 摧毁 .git
- 现象：为做「e2e 失败是否预先存在」的基线对比而执行 `git stash push`，随后 `.git/refs` 目录与 `.git/objects/pack/*.pack` 被删除，git 报 "not a git repository"。
- 根因：`NODE_OPTIONS=--require .../node-language-shim.cjs`（WorkBuddy CLI 的 safe-delete shim）劫持 fs.unlink/rmdir，git 的 ref 更新与 repack 被误伤（此前 pnpm 建临时目录也被它绊倒）。
- **铁律（跨项目）**：本机所有 git 命令一律 `env -u NODE_OPTIONS git ...`；**禁止用 `git stash`**（改用临时目录 + `git show HEAD:path > file` 做基线对比）。
- 恢复步骤（全部成功）：reflog 取 SHA → `mkdir .git/refs/{heads,remotes/origin,tags}` 仍报 bad object（pack 已丢）→ 删掉失效 refs → `git fetch --tags origin '+refs/heads/*:refs/remotes/origin/*'` → `git update-ref refs/heads/main <sha>` + `update-ref refs/remotes/origin/main <sha>` → `git reset --mixed HEAD` 重建 index（工作区改动完好无损）→ `git reflog expire --expire=now --all` 清掉失效 reflog 告警。本地对象丢失但远端完整，零数据丢失。
