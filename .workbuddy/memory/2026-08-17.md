## 调研 dsh 论文（《时空可组合性的编程范式》）
- 论文仓库: github.com/cordiverse/paper（PDF 在 paper.pdf），Draft 2026-08-13，80+ 页，20+ 定理，preprint 仍在修订。
- 作者: Yifan Shi（北大/DeepSeek，Koishi & Cordis 作者 shigma）、Wei Zhang（北大副教授）、Tianyi Cui（崔添翼，DSH 团队负责人）。
- 核心问题：现代软件（插件系统、自进化 Agent harness）需要“动态组合”，但形式化基础缺失。分两个正交维度：
  - 时间可组合性 = 可逆效应 Revertible Effects：组件卸载时逆变换自动回滚副作用（LIFO）。
  - 空间可组合性 = 响应式共效应 Reactive Coeffects：依赖声明 + 上下文变化通知激活/停用。
  - 统一：Effect 与 Coeffect 合并为单一 Context 类型；元定理证明整系统最终态 ≡ 按最终配置重加载一次。
- Cordis = TypeScript 元框架（“Meta-Framework for Modern Applications”），已实现：ctx.effect()/Fiber/DisposableList、inject/notify、声明式 Loader + HMR。已在 Koishi 验证 4 年 / 4000+ 插件。
- dsh 落地：一切皆插件（model/tool/session/sandbox/loop/UI 全挂 Cordis ctx）；Profiles+Bundles 分层组合 + cordis.patch.yml 补丁；事件为扩展点；seams 可整段替换；创造模式（运行时自挂/卸临时插件，信任级=Shell，仅驻内存）。
- 与 OrchDesk 关系：dsh 已有桌面壳 apps/qurvis（Electron）。构建 OrchDesk 的关键资产 = 可逆效应带来的“无损热插拔/自进化”能力；注意论文局限——系统边界外副作用不可撤销（如已外发的消息），Agent 自生成插件需更强静态分析。

## 精读 paper.pdf 完成（全 88 页）
- 已提取全文为 references/paper/paper.txt（供后续检索），并写结构化精读笔记 references/paper/README_精读.md。
- 核心：effect→revertible（Γ→Γ×(Γ→Γ)，twisted monoid 𝔗Γ，accumulator φ=LIFO 回滚）；coeffect→reactive（Σ 依赖表 + notify 分类 activating/deactivating/neutral + isolate/interception）；统一 Γ∞=Γ×(Γ→Γ)×Σ。Cordis 用 ctx.effect / ctx.use / ctx[@@store|isolate|intercept] 落地；Fiber 惯性状态机 + Loader 增量对账 + HMR 事务回滚。
- 对 OrchDesk 最关键局限：6.1 系统边界——边界外已发出的操作（write 字节/send 报文/已外发消息）不可撤销，只能 withhold 或 compensation（且补偿的元定理需重证）；6.3 沙箱必须靠外部机制（SFI/沙箱进程/容器），语言级访问控制挡不住恶意组件；6.6 共效应仅按键名名义链接，有接口漂移/键碰撞风险。
- 结论点名未来最重要验证方向 = 自进化 Agent harness（即 OrchDesk 的定位）。
