## BUG-W04 修复（ponytail 模式）
- 根因**推翻旧归因**（非 Node 22 / 非历史重建）：`git-raw-commits@5.0.1` 输出不再带 `-hash-` 分隔符（实测 274 行命中 0 次），而 `conventional-commits-parser@6.4.0` 仍靠它切分 → 整段历史被吞成一条 `chore:` 提交 → angular preset 过滤 → 退出 0、产出 0 字节。非版本漂移（core v8 本就声明 ^5.0.0），是上游 v5/v6 迁移的契约断裂。
- 修复：新增零依赖 `scripts/changelog.mjs`（git `--pretty` 用 `\x1f`/`\x1e` 自切分 + Keep a Changelog 分组 + SemVer 推断 + 幂等写入 + `--selftest`）；`package.json` 的 `changelog` 脚本切到它。
