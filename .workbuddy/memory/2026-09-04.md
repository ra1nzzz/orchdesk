## ⚠️ git push 凭据坑（2026-09-04 复发风险，见 user-level 记忆）

- **症状**：`git push origin main` 报 `fatal: could not read Username ... terminal prompts disabled`（非网络，直连通、ls-remote 匿名 OK）。
- **根因**：`~/.git-credentials` 有两条 github.com 条目——`x-access-token`（已失效，排**第一条**）遮蔽了有效的 `ra1nzzz` 个人 token。git credential helper 返回第一条（x-access-token）→ GitHub 401 → 回退要用户名交互失败。
- **绕法**：不依赖 helper，用 ra1nzzz token 内嵌 URL：`RAT=$(awk -F'[:@]' '/ra1nzzz/{print $3}' ~/.git-credentials | head -1)` 然后 `git push https://ra1nzzz:${RAT}@github.com/ra1nzzz/orchdesk.git main`（token 40 字符，成功）。main 7478420..26f96ea、tag v0.14.0 均经此推送成功。
- **注意**：awk 提取 token 用 `$3`（-F'[:@]'），不是 $NF（会取到 host）；sed 提取也可能因格式返空。勿擅自删改 .git-credentials（敏感）。建议用户手动清掉失效的 x-access-token 条目恢复 helper 可用。
