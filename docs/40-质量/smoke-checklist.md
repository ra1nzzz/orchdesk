# 实机冒烟清单

> 本页是「桌面会话实跑验收」的操作清单。自动化能跑的部分见 [质量门禁](quality-gates.md)（`npm run verify`），
> 本页只收**必须真 GUI / 真 PTY / 真文件系统**才能判定的项 —— 这类项 agent 宿主环境跑不了（BUG-W02 收窄后仅剩
> 「无显示器 + 无用户会话」这一条限制，见 [60-BUG](../60-BUG/index.md)）。
>
> **回填规则**：一项勾选 = 亲眼看到预期结果。没跑到的不要勾，跑挂的写进 `失败记录` 表并开 BUG，
> 不要为了全绿放宽预期。勾选后同步回勾 [PLAN](../30-开发/PLAN.md) 对应验收项 + 在
> [CHECKPOINT](../00-项目/CHECKPOINT.md) 登记批次。

## 0. 前置

- [ ] 安装/覆盖安装 Setup 或解压 portable 版，**先跑一次数据目录自备份**（升级前备份，PRD FR-4.3）。
- [ ] 记录本次被测版本号、commit、产物哈希（登记进 [99-归档](../99-归档/index.md)）。
- [ ] 打开 DevTools（终端/文件/浏览器面板的降级徽标与控制台日志是判定依据）。

## 判定口径（避免假绿）

1. **降级不算通过**：PTY 徽标显示「管道」、浏览器 `via` 走兜底 —— 功能可用但必须记 FAIL 并开 BUG，
   否则「跑通了」会掩盖「其实是兜底跑通的」。
2. **未接入 ≠ 为空**：面板显示「未接入主进程」是桥缺失，与「没有数据」是两回事，判定前先分清。
3. **不为了全绿放宽预期**：本清单的价值在暴露问题，不在凑勾选数。
