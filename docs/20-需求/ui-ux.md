# OrchDesk UI/UX 规范

> 本页是「界面与交互」的 canonical 责任方。需求来源见 [PRD](PRD.md)；原型实现在 `prototype/orchdesk.html`（v0.6）。
>
> **v1.1 变更**：按原型 v0.2→v0.6 收敛重写。导航从 12 项收敛为 3 入口（会话/插件/设置）；会话=一等公民；亮点功能视觉弱化；布局规格对齐 v0.6 实际实现。

## 1. 设计原则

1. **会话=一等公民**：默认落地页是会话，打开应用即可对话。不做 Dashboard 首屏。
2. **亮点视觉弱化但基于事实执行**：脑-手解耦 / 多 Agent 编排 / 意图识别以插件形式存在，在会话中仅以 inline 徽标/提示出现；深度操作进插件页。
3. **一切皆插件**：模型/沙箱/授权/记忆/编排/意图均以插件形式挂 ctx；大部分能力收进设置页。
4. **状态可观测**：关键状态（授权/沙箱/数据/运行时）在设置页顶部 4 格状态条一眼看完；会话中的意图/授权状态以 inline 点呈现。
5. **授权不打扰但可控**：低风险安静通过，高风险清晰拦截；composer 授权芯片是日常入口，深度配置在设置页。
6. **本地感**：所有数据本机；界面明确标识「本地运行」。
7. **可恢复可见**：插件热插拔、会话分叉/回放的结果立即可见（体现可逆效应）。

## 2. 信息架构（3 入口）

```text
OrchDesk
├── 会话          默认落地页（FR-2）：项目分组侧栏 + 消息流 + composer + 上下文栏
├── 插件          一切皆插件（FR-3）：左栏 5 分组 + 主区插件卡片
└── 设置          能力收口（FR-4）：4 格状态条 + 模型/沙箱/授权/桌面集成/数据/凭据/关于
```

**取消的导航项**（v0.1 的 12 项）：Dashboard / Agents / Conversations / Orchestration / Skills / Models / Prompts / Memory / Sandbox / Authz / Intent。其能力分别并入会话页（Conversations）、插件页（Skills/Agents/Orchestration/Intent/Memory）、设置页（Models/Sandbox/Authz/Prompts）。

最左导航栏（图标列，56px）仅含：会话图标 / 插件图标 / 设置图标 / 主题切换 / 入门向导。

## 3. 总体布局

应用窗口采用单 frame 居中（`min(1400px,98vw) × min(900px,96vh)`），内部为顶部标题条 + 主体 grid。

### 3.1 会话页布局（4 列 grid）

│ 导航 │ 会话侧栏    │ 会话主区               │ 上下文栏      │
│ 56px │ 270px      │ 弹性                   │ 300px(可折叠) │
│      │ 项目分组    │ 标题 + 消息流 + composer│ display:none │
│      │ +会话列表   │                       │ 收起时移出流  │

- 折叠箭头随状态旋转：展开朝右，收起朝左。

## 4. 关键页面

### 4.1 会话页

#### 4.1.1 会话侧栏

- **项目分组**：每组 = 项目头 + 会话列表。
  - 项目头：chevron 折叠 + 项目名 + 会话数 chip + `··` 菜单按钮（hover 才出现，`opacity:0` → 父级 hover 显示）。
  - 项目头 `··` 菜单：打开项目目录 / 归档项目（走二次确认 modal）。
  - 会话项：会话名 + `··` 菜单按钮（hover 才出现）。
  - 会话项 `··` 菜单：复制会话 ID（`navigator.clipboard`）/ 重命名（modal）/ 创建分支（modal，继承 SessionEvent 前缀）/ 归档。
- **悬浮 + 新建按钮**：侧栏底部居中圆形 + 按钮，hover 弹出「新建会话」气泡 tooltip（右侧）。
- **已归档**：单独折叠组，含还原入口。

#### 4.1.2 会话主区

- **标题行**：会话名（16px）+ 当前专家 badge（info 色）+ 右侧折叠箭头按钮。**不显示模型名/会话 ID**（v0.6 收敛）。
- **消息流**：
  - 用户消息（右对齐气泡）+ Agent 消息（左对齐，含头像、meta、工具调用展开、step 消耗、触发的授权）。
  - 每条 Agent 消息底部：TRACE 反馈按钮（正面/负面/中性），点击后脱敏遥测。
  - SubAgent 以 inline 芯片呈现：`[SubAgent] W-108 临时任务 · 执行中…` → 完成后变 `已回收并销毁（即用即走）`。
  - 高风险确认 banner（inline，非 modal）：`意图 · 待确认 该请求含「删除文件」高风险动作 + 确认执行/拒绝按钮`。
- **右侧上下文栏**（可折叠）：选中会话的属性、SessionEvent 事件流、授权请求内联卡片。收起时 `display:none`。

#### 4.1.3 composer

```text
┌──────────────────────────────────────────────────────────┐
│ textarea（向 当前专家 发消息…）                            │
├──────────────────────────────────────────────────────────┤
│ [+加载技能] [@引用专家] [授权芯片]    [意图点] [模型▾][思维━━●] [发送] │
└──────────────────────────────────────────────────────────┘
```

- **左下三件套**：
  - `+` 加载技能：modal 列出已装插件 + 技能市场项，注册为本次会话 effect，离开会话即卸载。
  - `@` 引用专家或专家团：modal 列出 8 专家 + 3 团，以 SubAgent 形式参与本次回复。
  - **授权芯片**：默认「工作空间写」（绿点）；点击 → 二次确认 modal 警示 L4 不可逆 → 确认后切「FULL ACCESS」（warn 橙 + pulse）；再点降级。
- **右下控件**：
  - 意图识别状态点：「意图识别：本地模型 ACT」（绿点）。
  - **模型选择按钮**：显示当前模型名，多选时显示「N 个模型」；点击弹 modal，按提供商分组多选 + 全选/取消全选 + 清空。
  - **思维等级滑竿**：inline range slider（min=0 max=3 step=1），拖动实时更新标签（关闭/标准/深度/最大），**不弹 modal**（v0.5 收敛）。
  - 发送按钮（primary）。

### 4.2 插件页

#### 4.2.1 左栏 5 可折叠分组

| 分组 | 内容 | 默认状态 |
|---|---|---|
| 内置插件 | 首批 5 插件（意图识别/TRACE/脑手解耦/多Agent编排/OrchClaw Hub） | 展开 |
| 插件市场 | Git/PDF/浏览器/邮件/可视化 等 | 展开 |
| 技能市场 | guanji/consolidate/aihot/kimi-webbridge 等（观雅集来源） | 展开 |
| 专家·专家团 | 8 专家 + 3 团 | 展开 |
| 连接器 | GitHub/飞书/企微/腾讯文档/Notion/Linear/TAPD/钉钉 | 展开 |

- 每组：chevron 折叠 + 组名 + 计数 chip；点击组头 toggle。
- 组内项：名称 + 状态 badge（启用/关闭/延后/需授权）+ 操作按钮（安装/配置）。

#### 4.2.2 主区（main-inner, max-width:960px, padding:20px 28px）

- 标题 + 副标题（「一切皆插件——能力以插件形式挂载；启用 = 注册 effect，停用 = 注册回滚（无残留）」）。
- **插件卡片**（每张）：
  - 头部：名称 + 能力声明 chip 行（`github.write` / `agent.dispose` / `memory.commit` 等，高风险标 warn 橙）+ 启用/停用开关 + 配置按钮。
  - 配置内联展开（toggle `.open`）：配置项表单 + 审计日志 + 卸载并回滚按钮。
- **技能市场网格**：需授权项标徽标，安装走 FULL ACCESS 二次确认。
- **能力审查区**（右栏/底部）：当前会话已加载的能力清单 + 来源 + 信任级。

### 4.3 设置页

#### 4.3.1 顶部 4 格状态条

| 授权模式 | 沙箱 | 数据目录 | 运行时 |
|---|---|---|---|
| 工作空间写 / FULL ACCESS | win-acl / sandbox-exec / landlock | 路径（可打开） | Node x.x / dsh x.x |

#### 4.3.2 分组（main-inner, max-width:960px）

- **模型管理**（图标 bot）：提供商分组表 + search input（按名称/提供方）+ 测试连通性按钮 + 用量追踪。
- **沙箱**（图标 shield）：backend 选择 + 白名单目录编辑 + 日志入口。
- **授权**（图标 shield）：模式切换（default/trusted/paranoid）+ L0–L4 行为矩阵 + 永久授权白名单（可撤销）+ 审计日志。
- **桌面集成**（图标 settings，2×3 网格）：系统托盘 / 全局快捷键 / 登录自启动 / 自动更新 / 悬浮窗 / 开机提醒。
- **数据目录**（图标 folder）：路径 + 打开目录 + 导出快照 + 内容清单（sessions.db / memory / plugins / logs）。
- **凭据**（图标 at）：AES-256-GCM 加密存储，掩码显示，导入/导出。
- **关于**：版本号卡片化 + 入门向导重开按钮。

## 5. 关键交互

### 5.1 授权请求

- 日常入口：composer 授权芯片（工作空间写 ↔ FULL ACCESS，升级走二次确认 modal）。
- L1/L2：上下文栏内联卡片（允许 / 拒绝 / 始终允许此类）。
- L3/L4：模态弹窗，L4 需二次确认。
- 每个请求展示：操作类型、目标路径/命令/域名、参数、风险等级、发起 Agent（含其在编排树中的位置）。

### 5.2 意图确认门（4-gate 可视化）

意图网关判定 CONFIRM 时，在会话主区 inline 展示：原始意图摘要、Funnel 各门（F1–F4）通过情况、M3 编译后的确定性动作预览、「执行 / 修改后执行 / 拒绝」。

### 5.3 Worker 生命周期（SubAgent 芯片）

SubAgent 卡片实时流转 `create → running → completed/failed → disposed`，完成后成果（artifacts）自动递交主会话并弹出「已销毁」提示——强化「即用即走」心智。会话中仅以 inline 芯片呈现，不占独立区域。

### 5.4 边界外补偿

外发类操作（发消息/网络请求/写共享文件）执行前显示「不可撤销」警示条；执行后在审计中提供「补偿动作」按钮（如撤回/删除），补偿结果入日志。

### 5.5 模型多选

- composer 模型按钮点击弹 modal：按提供商分组（Anthropic / OpenAI / DeepSeek / Ollama 本地），每个模型 checkbox 多选。
- 每组有「全选/取消全选」；底部「清空」+「确认（N 个）」。
- 多选时按钮变 CEO 色（紫），显示「N 个模型」。
- 发送时多模型协同推理（具体协同策略由模型插件定义）。

### 5.6 思维等级滑竿

- inline range slider，0-3 对应 关闭/标准/深度/最大。
- 拖动实时更新右侧标签，无需 modal。
- 等级越高推理越周全但耗时越长；对所有选中模型生效。

### 5.7 项目/会话菜单

- 所有 `··` 按钮默认 `opacity:0`，hover 父元素才出现（`.proj-head:hover .pm` / `.sess:hover .sm`）。
- 菜单为浮动 pop，点击外部关闭。
- 归档操作走二次确认 modal；重命名/创建分支走 modal 含输入框。

## 7. 桌面集成（2×3 网格）

| 能力 | 行为 |
|---|---|
| 系统托盘 | 显示在线 Agent 数与待授权徽章；右键快捷操作（暂停全部 Agent、打开主窗） |
| 全局快捷键 | `Ctrl+Shift+Space` 唤起快速指令窗（向当前专家发任务） |
| 登录自启动 | 可选（默认关） |
| 自动更新 | 检查更新 + 下载提示，更新前自动快照数据目录 |
| 悬浮窗 | 可选悬浮快捷输入窗 |
| 开机提醒 | 可选开机后提醒待办会话 |

## 8. 可访问性与本地化

- 中文首发，i18n 预留；键盘可达全部授权操作；对比度满足 WCAG AA。
- 所有 `··` 菜单按钮虽 hover 才显示，但须键盘可达（Tab 聚焦时显示）。

## 9. 原型对照

本规范所有结构均以 `prototype/orchdesk.html`（v0.6）为参照实现。后续开发按本规范落地真实 UI，不得偏离 3 入口与会话优先原则。原型与规范的差异（如演示用 mock 数据）在实现时替换为真实数据源。
